# v0.12.5 source release record — 2026-11-05

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release aligns maintained-memory prompt projection, built-in
skills, natural-language search, one-step `agent_memory_edit` publication,
nested project reference directories, single-run reflection backlog delivery,
and right-aligned extension footer statuses.

## Maintained-memory projection, search, one-step commit and built-in skills

- `lib/agent-memory/engine/schema.ts` projects all non-index `system/**` files
  (`system/persona.md`, `system/human/identity.md`, `system/human/notes.md`,
  `system/human/prefs/*.md`) and active-project non-index
  `projects/<id>/system/*.md` files into `<mahiro-managed-memory>`, and supports
  nested project reference groups (`projects/<id>/reference/<group>/<slug>.md`
  and `projects/<id>/reference/<group>/index.md`).
- `lib/agent-memory/retrieval.ts` strips bilingual English/Thai conversational
  stopwords when content terms remain, supports multi-term coverage (`>= 2` and
  `>= 50%` for 3+ content terms), and supports `|` / `OR` disjunction clauses
  across both in-memory and streaming searches.
- `extensions/mahiro-agent-memory.ts`, `lib/agent-memory/experimental-runtime.ts`
  and `lib/agent-memory/runtime.ts` add optional `commit: true` and
  `allowShrink?: boolean` to `agent_memory_edit` (and scope-guarded index upkeep
  to `remember`), automatically syncing ancestor `<dir>/index.md`, parent
  `<dir>/index.md` and root `index.md` pointers and integrating/publishing in one
  step.
- `skills/` adds six built-in skills (`maintaining-core-memory`,
  `maintaining-deferred-memory`, `initializing-memory`, `context-doctor`,
  `syncing-memory-filesystem` and `creating-skills`), and
  `lib/agent-memory/experimental-runtime.ts` delivers frozen reflection backlogs
  of up to 32 episodes in one writer run without chaining follow-up writers.

## Right-aligned extension footer statuses and current guide corrections

- `lib/footer.ts` retains other extensions' status cells once, sorts them by key
  and packs them as a right-aligned group. When space permits, the first packed
  status row shares the first usage row beneath the model/thinking area, with at
  least three columns of separation. Remaining rows stay right-aligned below the
  core fields.
- `test/footer.test.ts` and `check-geometry.ts` add coverage for the shared-row
  layout and narrow-width wrapping without dropping status text.
- `docs/status.md`, `docs/agent-memory.md`, `docs/agents.md`, `docs/bootstrap.md`,
  `docs/claude-ui.md`, `docs/development.md`, `docs/getting-started.md` and
  `docs/letta-parity-roadmap.md` document current permission, maintained-memory,
  RTK and integration ownership.

## Verification and boundaries

The source is checked with `pnpm format`, `pnpm check:fast` (`check:state`,
`check:types`, `check:format`, `check-package.mjs` and `check:docs`),
`skills/creating-skills/scripts/validate-skill.mjs`, and focused
maintained-memory, retrieval, schema-parity, starter, Palace, reflection,
runtime and lifecycle suites. Source and deterministic SDK checks do not
establish provider behavior, live profile state or human visual acceptance in
every environment. Installing or upgrading this source release still requires an
intentional profile preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
