# v0.11.0 source release record — 2026-10-28

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This minor source release bounds disposable test state, restores path/index-driven
maintained-memory discovery and replaces repeated MH tool activity rows with a
compact truthful terminal hierarchy.

## Bounded test state and explicit QA tiers

- The whole `.agent-state` tree is checked strictly below 1 GiB at explicit
  checkpoints without deleting private memory, retrospectives, learnings, inbox
  or metrics.
- Disposable SDK and candidate fixtures register exact newly created roots,
  clean up idempotently on success and failure, and retain process-exit fallback
  without pruning unknown or live paths.
- State is measured before cleanup so a failing fixture cannot hide a budget
  violation by deleting its evidence first.
- Fast static checks, source behavior tests, public-SDK integration and the
  combined release gate are separate commands. A focused or fast pass is not
  reported as a passing heavy tier.

## Path/index maintained-memory Palace

- `Core.md`, `index.md`, the native persona and current-project overview and
  conventions form a narrow always-loaded discovery tier. Detailed human and
  project context remains progressively loaded by exact path, namespace or
  bounded lexical search.
- Palace health distinguishes broken links on discovery-critical sources from
  advisory links in detail and historical material while retaining completeness,
  file and total-byte ceilings as health gates.
- Scoped archive validation accepts deeply nested legacy migration paths while
  preserving prefix, scope, revision, forgetting and CAS fences.
- Retained-conflict metadata can be listed without recovering bodies. Exact
  inspection and discard still require full recertification and fail closed when
  historical content no longer satisfies current forgetting or authority.
- The source changes support bounded removal of verified duplicate legacy
  projections. Private memory contents and local migration receipts are not part
  of this public release.

## Compact native MH activity ladder

- MH tool calls render as one neutral `●` identity row with a subordinate `⎿`
  result row instead of repeated feature headings and stale pending cards.
- Ordinary final results say `Returned · not acceptance`; they do not imply
  workflow completion, worker completion, success or human acceptance.
- Partial and error states remain explicit. Collapsed output exposes at most one
  prioritized structured fact row, while expansion preserves exact captured
  output and details.
- Errors, reasons and nonzero blockers, issues or conflicts take priority before
  state, stage, revisions, next action, identifiers and counts.
- Long revisions are abbreviated only in collapsed output. ANSI/OSC controls,
  Unicode and narrow terminal widths remain sanitized and bounded.
- At very narrow widths, framing and padding disappear before truth-bearing text.
  The ordinary returned-state text uses the readable semantic `muted` tone while
  the hierarchy marker and pre-execution `requested` remain `dim`; partial and
  error states retain warning and error tones.
- Public Pi renderer APIs, `renderShell: 'self'`, raw details, non-TUI behavior,
  global theme ownership and footer/header contracts remain unchanged.

## Verification and boundaries

The final source is checked with formatting, strict authored TypeScript,
documentation/package validation, focused workflow renderer coverage, independent
review and the serial combined release gate. Source and deterministic SDK checks
do not establish provider behavior or visual quality in every terminal. Native
profile activation, session reload and Mahiro's rendered acceptance were recorded
separately before publication; installing this source release still requires an
intentional profile preview/apply and fresh load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. GitHub's automatic source archives
are verified separately. This package remains `private: true` / `UNLICENSED`;
this is a GitHub source release, not npm publication or a license grant.
