# v0.9.1 source release record — 2026-10-27

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This hotfix removes the secondary compatibility alias introduced in v0.9.0.
Mahiro identified that exposing two command names made the branch-local Todos
surface needlessly easy to confuse with the canonical cross-session `tsk` board.

## One public command

- `/mh-todos` is now the only registered slash command for branch-local session
  todos and remains the **Todos** entry in the `/mh` workflow hub.
- No secondary compatibility slash command is registered or advertised by current documentation.
- Internal `mh_task_create`, `mh_task_get`, `mh_task_list` and `mh_task_update`
  model tools keep their names. Existing `mahiro-session-tasks-v1` journal data,
  revisions, dependencies, retention/reminders and reload/fork behavior are unchanged.
- RPC and non-TUI contexts retain the selector fallback through `/mh-todos`.
  Removing the alias creates no replacement journal and performs no data migration.

Historical v0.8.0 and v0.9.0 release notes remain unchanged because they accurately
record the commands those versions shipped.
