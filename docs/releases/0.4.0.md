## Prepared scope

- **Session steps:** four namespaced tracking tools and `/mh-tasks` for CRUD,
  revisions, dependencies, manual blocked-start warnings, reopen/delete and
  bounded quiet/compact views. Never-expire retention and reminders-off are
  conservative defaults; four-native-turn retention and transient reminders are
  explicit session-local options. No worker execution, RPC or task-board swap.
- **Editable staging:** `/mh-queue` owns pre-handoff text/images with an isolated
  modal, edit/cancel, explicit image removal, lane/FIFO positioning and confirmed
  single handoff. Capture defaults off. Stable row/attempt IDs correlate actual
  native branch observations, not void send returns or aggregate pending state.
- **Branch-local continuity:** public appendEntry/getBranch operation journals
  rehydrate after native reload/resume and inherit fork prefixes without copying
  external stores. Revision/generation checks reject stale views. Unconfirmed
  attempts remain locked/retained; no automatic resend or timeout deletion.
- **Owner-installed child controls:** the existing public subagents patch adds
  read-only, identity-bound attestation for the creator's actual bare
  `ask_parent`/`notify_parent` definitions. Root classification no longer mistakes
  these for unrelated SDK tools; ordinary PSS allow/ask/deny remains mandatory.
  Unowned definitions, aliases, missing bridges and revoked owners fail closed.
- **Existing owners retained:** thirteen guards-first manifest entries, native
  utilities registration, appearance-only `/mh-ui`, unchanged authored footer,
  header, palette and usage semantics. Explicit installation includes four
  tracking-tool grants; source loading provisions nothing.

Independent upstream functional evaluation informed an owned implementation,
not adoption/copying of an upstream execution package. The existing subagents
23.4.1 authored patch changes its narrow attestation ABI without a version bump.
No new dependencies, immutable upstream guard/oracle edits or profile/auth/model
changes are part of this source preparation. Exact package/provenance version pins move together to 0.4.0.

## Evidence and limits

Source/model tests and genuine public SDK/Faux fixtures exercise task lifecycle,
branch independence, reminders/retention, modal text/image preservation, storage
failure, stale-generation rejection and correlated queue records. The public UI
fixture is scripted: it is not actual native terminal, provider, rendered visual
or human acceptance. Separate offline SDK/Faux fixtures exercise genuine
creator-installed controls against production Root/PSS, scripted approval and
refusal, unrelated SDK definitions and lifecycle revocation. Those are not
installed activation or external inference. Full check/geometry, fresh independent review, intended
native TUI/install checks and publication artifact verification remain distinct
release gates; a checklist is not their receipt.

Staging cannot edit/cancel already-native pending rows. Recorded means matching
native journal observation only, never model completion or human acceptance.
Native session persistence is host-owned; journal limits and retained historical
images are documented in the current utilities guide. A discarded attempted row
may still be pending natively, and manual recreation can duplicate delivery.

Follow [safe upgrades](../getting-started.md#upgrade-safely) for intentional
activation. Commit, push, tag/release, profile install and reload require their
own authorized scope; none is performed merely by preparing these files.
