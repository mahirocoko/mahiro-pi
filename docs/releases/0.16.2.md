# v0.16.2 source release record — 2026-11-27

[← Documentation](../README.md) · [Development and release](../development.md)

## See progress in T3 Code

- Pi RPC clients that render extension statuses can show branch-local Todo progress above the input. The status shows the active step or pending count and clears when no steps are open or Todos view is off.
- `/mh-todos status` returns a read-only summary of step statuses and open dependencies without starting a model run. Bare `/mh-todos` still opens the existing management UI.
- The optional Orch extension distinguishes dispatch admission, queueing, a running `implementer`, and terminal outcomes in RPC. A finished worker is ready for Main review; it does not complete a Todo. Switching Orch off disables new dispatch, not a worker already running.

The compact Pi TUI presentation is unchanged. This release uses T3 Code's existing Pi status and notice surfaces; it does not patch T3 Code or add an expandable checklist or child thread.

## Persistence advisory

The existing advisory for `openai/gpt-6.1-terra` also applies to `openai/gpt-6.2-sol` on eligible primary user runs. It does not change models, permissions, or turn scheduling.

This is a GitHub source release, not npm publication or automatic activation in a running session. Private state is excluded.
