# v0.12.2 source release record — 2026-11-03

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release improves maintained-memory reflection ergonomics,
statusline visibility, worker turn-budget completion and readable project slug
registration.

## Reflection statusline, worker budget integration and project slugs

- `lib/footer.ts` and `lib/agent-memory/experimental-runtime.ts` publish the
  active reflection mode and unreviewed step progress (`😴 x/25`, `🗜️ compact`,
  `💤 off`) in the `mahiro-memory` statusline cell, refreshing on session start,
  settled turns, worker completion, policy updates and project initialization.
- `lib/agent-memory/experimental-runtime.ts` injects the leased baseline
  `<mahiro-managed-memory-view>` (`Core.md`, `index.md`, `system/persona.md`,
  and project `system/overview.md` plus `system/conventions.md`) into the
  identity-bound `managed-memory-writer` system prompt so the worker can edit
  and commit within its 8-turn budget without redundant discovery reads, and
  integrates a ready view (`value.ready === true`) when the final commit turn
  coincides with turn-budget exhaustion (`turnBudget.phase === 'exhausted'`).
- Primary `before_agent_start` surfaces an explicit reminder inside
  `<mahiro-managed-memory>` when an uncommitted primary draft is open, and
  `/mh-memory remember <text>` dispatches a bounded background reflection pass
  after persisting the note to `system/human/notes.md`.
- `resolveProjectSlug` in `lib/agent-memory/experimental-runtime.ts` derives
  readable collision-checked project slugs from the workspace directory name
  (or an explicit `projectId` in `init-project`) within the 128-project
  configuration bound while preserving active Palace viewer leases, and
  `/mh-memory init` adopts human-forked interactive TUI sessions before
  initializing project memory.

## Verification and boundaries

The source is checked with Biome formatting, strict authored TypeScript,
package and documentation validation, whole-state budget accounting, independent
reviewer verification and focused footer and reflection-runtime suites. Source
and deterministic SDK checks do not establish provider behavior, live profile
state or human visual acceptance in every environment. Installing or upgrading
this source release still requires an intentional profile preview/apply and
fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
