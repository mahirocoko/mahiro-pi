## Start work from `/mh-goal`

Run `/mh-goal <objective>` and confirm the full objective. Pi saves the Goal, then requests one native agent turn in the same eligible idle primary session. The agent reads the saved mission and begins the first authorized action. The command records a starter completion criterion; the agent can add a plan, next action, evidence, and blockers to the same Goal as the work requires. Human verification remains separate.

If a run was already active, another run began during confirmation, messages are pending, or no model is selected, the command saves the Goal without requesting a kickoff. A normal message can start work later. Status, pause, resume, and model-tool creation do not start turns. There is no automatic retry or continuation loop.
