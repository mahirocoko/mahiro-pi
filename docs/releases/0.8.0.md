# v0.8.0 source release record — 2026-10-26

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This feature release gives branch-local session steps a native overview designed
for quick terminal scanning. It preserves the existing journal, revision,
dependency and non-acceptance contracts while replacing the TUI command's nested
selector entry point with a width-safe keyboard-driven panel.

## Native task overview

- `/mh-tasks` opens a centered boxed overlay in interactive TUI sessions. The
  panel presents completion progress, hierarchical rows, selected-step detail,
  session settings and available shortcuts without replacing Pi's global header,
  footer or editor.
- Completed, in-progress, pending and dependency-blocked steps have distinct
  markers. An in-progress row can expose a bounded description, while task
  management retains the complete task ID and fields through the existing journal.
- Navigation remains bounded for long task lists. Rendering uses public TUI width
  helpers and grapheme-safe labels so narrow terminals, Thai, CJK and emoji do not
  break the frame.
- RPC and non-TUI contexts retain the existing native selector fallback. The tool
  schemas and branch-local journal remain unchanged.

## Safer task editing

- Dependency editing uses a toggle picker with complete task IDs instead of manual
  identifier entry. Submitting an unchanged selection avoids a no-op revision.
- Scripted native fixtures navigate according to the panel's actual task ordering,
  preventing tests from silently selecting the first row when another task was
  requested.
- Regression coverage exercises keyboard selection, narrow layouts, Thai/CJK/emoji
  width safety, multi-task targeting and dependency updates.

## Verification and boundaries

Final release verification completed the repository's aggregate `pnpm check` gate
on the complete versioned source: strict TypeScript covered 194 authored files,
source tests reported 709 pass, three intentional skips and zero failures, and the
genuine public SDK suite passed 41/41 with a natural exit. Formatting, package,
import, whitespace and documentation gates also passed. The explicit public-host
geometry smoke passed at 40/60/80/120/160 columns with a Thai/ZWJ round-trip; this
is not rendered acceptance. An earlier independent feature review reported PASS
after dependency discoverability and fixture-targeting
findings were corrected; final release-diff review remained a separate gate.

The panel is presentation over the existing task owner. Session steps still do
not execute workers, replace the cross-session task board, prove model completion
or establish human acceptance. Memory and compaction implementations are unchanged
in this release.

The package remains `private: true` / `UNLICENSED`. This is a GitHub source release,
not npm publication or a license grant. Historical [v0.7.1 notes](0.7.1.md) remain
unchanged dated evidence; current contracts live in the linked guides.
