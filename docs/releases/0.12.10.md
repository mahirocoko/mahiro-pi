# v0.12.10 source release record — 2026-11-06

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release expands ABI2 knowledge-history and Palace commit-diff
previews to 32-row pages with 8 KiB per-commit and 128 KiB aggregate fair-share
diff budgets, automatically upgrades legacy v1 `config.json` byte ceilings
during `/mh-memory init` (`init-project` and `migrate-v2`), and streamlines
`/mh-memory init` and `/mh-memory palace` draft/reflection lifecycle handling.

## 32-row knowledge history and fair-share multi-file diff allocation

- `lib/agent-memory/engine/data.ts`, `lib/agent-memory/knowledge-history.ts`,
  `lib/agent-memory/palace-handoff.ts` and `lib/palace-render/abi2-page.ts`
  expand `knowledgeHistory` and the Palace offset-zero history page from 8 to
  32 commits, raise per-commit diff previews from 4 KiB to 8 KiB and aggregate
  page diff budgets from 8 KiB to 128 KiB (within a 192 KiB reply ceiling and
  512 KiB frozen handoff DTO bound), and allocate diff budgets fairly across
  commits and across changed files within each commit.

## Automatic v2 budget upgrade and self-healing `/mh-memory init` & `palace`

- `lib/agent-memory/experimental-runtime.ts` and `lib/agent-memory/store.ts`
  automatically upgrade `config.json` byte ceilings to at least `coreBytes: 32768`,
  `indexBytes: 8192`, `fileBytes: 262144` and `totalBytes: 8388608` during
  `init-project` and `migrate-v2` so stores initialized with legacy v1 ceilings
  (`8192 / 2048 / 8192 / 65536`) do not fail with `reason: budget` when migrating
  `Core.md` or legacy `global/` and `deferred/` files.
- `lib/agent-memory/engine/data.ts` cancels the newly created management draft if
  an overlay write fails during `init-project` or `migrate-v2`, and refuses
  direct view `cancel` once a view is bound to a prepared operation plan so
  proposal hashes remain intact for operation recovery.
- `lib/agent-memory/experimental-runtime.ts` cancels any active primary draft
  before `init-project` or `migrate-v2`, cancels active background reflection
  jobs when opening `/mh-memory palace`, and allows `resolve()` to auto-register
  an unmapped `cwd` in `config.json` during Palace viewer startup.

## Verification and boundaries

The source is checked with `pnpm format`, `pnpm check:continuity-format`,
`pnpm check:fast` (`check:state`, `check:types`, `check:format`,
`check-package.mjs` and `check:docs`), and focused `agent-memory-engine`,
`agent-memory-knowledge-history`, `agent-memory-palace-handoff`,
`agent-memory-store` and `agent-memory-reflection-runtime` suites. Source and
deterministic tests do not establish provider behavior, live profile state or
human visual acceptance in every environment. Installing or upgrading this
source release still requires an intentional profile preview/apply and fresh
session load.

paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
