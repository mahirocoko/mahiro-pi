# v0.14.4 source release record — 2026-11-17

[← Documentation](../README.md) · [Development and release](../development.md) · [Current installation](../getting-started.md)

This patch avoids spending a full release-suite run discovering missing executor
prerequisites or a changed Node test-reporter default. It does not remove tests,
shorten the required verification tiers, change guards or claim to accelerate the
underlying full source suite.

## Fail before the expensive tiers

`pnpm check:release` now starts with `check:release:preflight`. The standalone
command reports the actual Node executable/version and probes Bun, fd (or its
supported fdfind alias), and ripgrep on the same process PATH using bounded
`--version` calls. Unsupported Node or unavailable tools produce a nonzero exit
before any suite starts.

Preflight is read-only. It does not install tools, download binaries, select a
Node version, inspect credentials, change profiles or grant permissions. Its
probe results describe that invocation, not package provenance or future PATH
stability. The existing fast, serial source, public-SDK and final state gates
remain in their original order after preflight.

## Select the output that SDK wrappers consume

The own-UI and usage SDK wrappers explicitly request Node's TAP reporter. Their
existing exit-status and successful-test assertions stay unchanged. This avoids
false failures when a supported Node version changes its default reporter while
the underlying native SDK tests actually pass.

Focused checks cover supported/unsupported Node versions, executable reporting,
fdfind fallback, failed and timed-out probes, real missing-PATH CLI refusal and
preserved release-tier order. The four affected SDK wrapper cases also passed on
Node 26 with explicit TAP. The combined source-release gate remains separate from
those focused checks and from installed or human acceptance.

## Publication boundary

This is a GitHub source release with an inspected tagged archive and SHA-256
manifest, not npm publication or a license grant. The package remains
`private: true` / `UNLICENSED`. Public Pi/PSS/subagent dependencies, installed
resources, memory authority and guard policy are unchanged. No live-session
reload or profile update is part of this tooling-only patch. Private state,
retrospectives, credentials and runtime evidence remain outside source archives.
