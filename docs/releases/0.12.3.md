# v0.12.3 source release record — 2026-11-04

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release expands `/mh` into an interactive Control Center with
two-column `SelectList` spacing, keyboard Back navigation, a unified Codex CLI
quota toggle in the Usage submenu, and Letta-aligned maintained-memory curation
and project initialization refinements.

## `/mh` Control Center, two-column menus and Usage submenu

- `lib/workflow-hub.ts` adds `createHubMenuPanel` and `selectHubMenu` using the
  public `@earendil-works/pi-tui` `SelectList` component so `/mh` and its
  feature submenus render two-column aligned `Label  state` rows, right-column
  descriptions, a dedicated focused-row description footer and keyboard Back
  navigation via `Esc`, `←` (Left Arrow) and `Backspace`.
- `extensions/mahiro-agent-memory.ts`, `lib/rtk.ts`, `lib/usage.ts` and the
  Goal, Code Evidence, UX and Execution Run workflow extensions register
  owner-authorized interactive submenus under `/mh` (and `<cmd> menu`) with
  consistent `← Back` navigation while preserving existing primary-session and
  authority fences.
- `lib/usage.ts` unifies the `Usage` submenu quota controls into a single
  `Codex CLI quota  on|off` toggle (`codex on` / `codex off`) derived from the
  active quota display state (`display.quota && snap.source === 'codex-cli'`),
  removing the redundant runtime-only `Quota source` menu row while retaining
  `/mh-usage source pi|codex-cli` command compatibility.

## Maintained-memory curation doctrine and `/mh-memory init` scan

- `lib/agent-memory/guidance.ts` refines the maintained-memory prompt guidance
  to emphasize organizing, updating and removing stale entries alongside
  progressive disclosure and anti-duplication.
- `extensions/mahiro-agent-memory.ts` scans bounded top-level project indicators
  (`package.json`, `AGENTS.md`, `CLAUDE.md`, `README.md`) during `/mh-memory init`
  and dispatches an initial background reflection pass when no reflection job is
  already active.

## Verification and boundaries

The source is checked with Biome formatting, strict authored TypeScript,
package and documentation validation, whole-state budget accounting, independent
reviewer verification and focused workflow-hub, integration, usage and
starter-memory suites. Source and deterministic SDK checks do not establish
provider behavior, live profile state or human visual acceptance in every
environment. Installing or upgrading this source release still requires an
intentional profile preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
