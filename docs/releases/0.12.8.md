# v0.12.8 source release record — 2026-11-06

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release writes persistent per-project Palace HTML snapshots
under `<profileDir>/viewers/memory-<project>.html`, expands committed file body
preview budgets to `8 KiB` per file and `128 KiB` aggregate with fair-share
allocation across in-scope files, and adds live `/mh-memory palace` TUI progress
indicators and concise browser-open notifications.

## Persistent per-project Palace HTML snapshots

- `lib/agent-memory/experimental-runtime.ts` writes the rendered ABI2 Palace HTML
  atomically (`0o600`) to `<profileDir>/viewers/memory-<project>.html` inside a
  private `0o700` `viewers/` directory on each `/mh-memory palace` invocation,
  overwriting the project's previous HTML snapshot in place and opening the local
  HTML file in the system browser while keeping the capability-scoped loopback
  viewer active until expiry or `/mh-memory palace close`.
- `lib/agent-memory/runtime.ts` extends `RuntimeConfig.openBrowser` with the
  optional rendered `filePath` argument alongside the capability URL.

## Expanded committed file body preview budgets and fair-share allocation

- `lib/agent-memory/engine/data.ts`, `lib/agent-memory/palace-structure.ts`,
  `lib/agent-memory/engine/replies.ts`, `lib/agent-memory/palace-diagnostic.ts`
  and `lib/agent-memory/palace-handoff.ts` raise the committed preview budget from
  `4 KiB` per file / `8 KiB` aggregate to `8 KiB` per file / `128 KiB` aggregate
  across up to 32 files, with fair-share allocation (`Math.floor(bodyBudget / remainingSlots)`)
  when remaining demand exceeds the remaining aggregate budget so later `system/*`
  files are not starved to zero bytes.
- `lib/palace-render/abi2-page.ts` adds `[8192, 128, false]` as the primary render
  tier while preserving the `256 KiB` frozen handoff and HTML transport ceiling.

## Live TUI progress indicators and notification refinements

- `extensions/mahiro-agent-memory.ts` displays a live `mahiro-palace` spinner
  widget and `⏳ Generating Memory viewer...` footer status while `/mh-memory palace`
  captures and renders the snapshot, clears both in `finally`, and notifies with
  the generated `File:` path and `Close: /mh-memory palace close` command.
- `AGENTS.md`, `docs/agent-memory.md`, `test/agent-memory-engine.test.ts` and
  `test/agent-memory-tree-lifecycle.test.ts` document and test the updated
  snapshot path, preview budgets and TUI lifecycle.

## Verification and boundaries

The source is checked with `pnpm format`, `pnpm check:continuity-format`,
`pnpm check:fast` (`check:state`, `check:types`, `check:format`,
`check-package.mjs` and `check:docs`), and focused `agent-memory-engine`,
`agent-memory-palace-handoff` and `agent-memory-tree-lifecycle` suites. Source
and deterministic tests do not establish provider behavior, live profile state
or human visual acceptance in every environment. Installing or upgrading this
source release still requires an intentional profile preview/apply and fresh
session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
