## Optional orchestration trial

`/mh-orchestrate` is a session toggle for an explicitly loaded extension. It starts OFF for a new session or after reload. Main keeps its own model and handles ordinary requests directly. When Main delegates an already authorized implementation, the trial uses the existing PSS-guarded Subagents tool and the configured `implementer` role.

The exact-role tool path requires the role's configured `provider/model`, declines fallback, and leaves the parent's conversation and assembled system prompt out of the worker input. Ordinary unflagged calls retain their behavior. Turning the trial OFF revokes new admission, including calls drafted during an earlier mode epoch. Native Subagents still owns any accepted worker and can deliver its normal completion turn. The footer distinguishes running work, finishing while OFF, and a terminal result ready for review; none of these states implies acceptance.

The default manifest, installer, profile settings, agent descriptors and alternative execution routes do not activate this trial. See the [operator guide](../orchestrator.md) for isolated opt-in composition and focused offline verification. This release does not include media inspection or provider changes.
