# v0.12.7 source release record — 2026-11-05

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release adds readable diff and written-content previews for
maintained-memory tools, surfaces specific call arguments and structured result
summaries across workflow and utility tools, and wires `recall_search`,
`recall_read` and `mh_code_map` into the shared `workflowRenderers` TUI
presentation.

## Readable memory tool previews and wrapped TUI rows

- `lib/workflow-ui.ts` adds `callMeta(name, args)` and
  `memoryPreviewLines(name, args, details, expanded)` for `agent_memory_edit`,
  `agent_memory_read`, `agent_memory_commit`, `agent_memory_manage` and
  `agent_memory_reflect`.
- `agent_memory_edit` call headers show the edit mode (`patch`, `replace`,
  `append`, `remove`, plus `+ commit` when `commit: true`), target `path` and
  optional `#section`. Successful results display a bounded `- `/`+ ` diff or
  written-content preview in collapsed mode and under a `Changes` section when
  expanded.
- `WorkflowText.render` wraps preview lines up to 6 rows in collapsed mode
  (`wrapRow`) so long single-line Markdown bullets remain legible without
  horizontal truncation, and applies `Update`-style row background fills
  (`toolDiffRemoved` / `toolDiffAdded` mixed with the active tool surface) plus
  bold word-level LCS change highlights (`diffWordSpans`) on paired `patch`
  lines when the active TUI theme exposes color primitives.
- `agent_memory_commit` displays `allowShrink` and abbreviated `rev` on the call
  row and lists integrated `files` (`+ <file>`) in the result preview.

## Specific call and result metadata across workflow, recall and Code Map tools

- `lib/workflow-ui.ts` extends `callMeta` and `workflowSummary` for
  `mh_task_update`, `mh_update_goal`, `mh_clear_goal`, `mh_code_evidence`,
  `mh_update_ux_workflow`, `mh_execution_run`, `mh_rtk`, `mh_code_map`,
  `recall_search` and `recall_read`.
- `extensions/mahiro-continuity.ts` and `extensions/mahiro-code-map.ts` register
  `registerWorkflowPresentation(pi)` and spread `workflowRenderers(name)` onto
  `recall_search`, `recall_read` and `mh_code_map`, rendering bounded hit counts
  and quote snippets in place of raw JSON payloads.
- `docs/workflows.md` and `test/workflow-ui.test.ts` document and test the
  expanded presentation coverage.

## Verification and boundaries

The source is checked with `pnpm format`, `pnpm check:continuity-format`,
`pnpm check:fast` (`check:state`, `check:types`, `check:format`,
`check-package.mjs` and `check:docs`), and focused workflow-UI,
workflow-integration, session-task-adoption, continuity-runtime and staged
code-map SDK suites. Source and deterministic SDK checks do not establish
provider behavior, live profile state or human visual acceptance in every
environment. Installing or upgrading this source release still requires an
intentional profile preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
