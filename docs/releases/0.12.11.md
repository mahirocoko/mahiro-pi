# v0.12.11 source release record — 2026-11-06

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release makes a newly installed managed-memory writer follow
its primary agent's current model at each dispatch. Existing canonical fixed
writer routes remain fixed on ordinary upgrades.

## Managed-writer route selection

- The source `agents/managed-memory-writer.md` descriptor now omits `model`.
  New installs use the current primary physical model; the writer's configured
  thinking level remains independent of the primary thinking setting and is
  `off` for inherited non-reasoning models.
- `lib/agent-memory/writer-route.ts` accepts either a canonical fixed
  `provider/model-id` or an omitted model slot. Public-catalog preflight rejects
  unavailable or virtual models and unsupported thinking levels; both ordinary
  and experimental memory runtimes pin the resolved model and thinking at spawn.
  An already queued or running writer keeps its dispatched route.
- Paired `--managed-writer-model inherit --managed-writer-thinking medium`
  flags can explicitly move an existing fixed route to inheritance after
  installer preview/review. Paired fixed-model flags remain supported. This
  change does not edit installed profiles, change the primary model or grant
  provider access.

## Verification and boundaries

Release metadata preparation ran `pnpm format`, `pnpm check:format`,
`pnpm check:docs` and `pnpm check:fast`. The combined `pnpm check:release`,
full source and public-SDK tiers were not run as part of metadata preparation;
those require separate release-gate authorization. Static checks do not
establish provider behavior, installed activation or human acceptance.
Installing or upgrading still requires an intentional profile preview/apply
and a fresh session load for descriptor changes. This source release is not
an installation or a profile update.

A later authorized publication must build and inspect its archive from the
annotated tag and attach a SHA-256 checksum manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
