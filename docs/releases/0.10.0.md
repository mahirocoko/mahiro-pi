# v0.10.0 source release record — 2026-10-28

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This source release brings theme and Todos refinements together with the memory,
permission and persistence work since v0.9.1.

## Presentation

- Four optional dark palettes—Claude, Obsidian, Ember and Nordic—are available
  through `/mh-ui` for preview and runtime selection. They are also packaged as
  Pi themes for selection through Pi's own theme settings. Apply and explicit Save
  remain separate; no global theme is selected automatically.
- Edit diffs use theme-derived addition and removal surfaces with stronger word
  emphasis, without painting trailing empty space. Native diff mode continues to
  follow Pi's host theme. The adapted built-in codemode presentation retains the
  native renderer and its lifecycle.
- The above-editor Todos widget is frameless and aligned with adjacent widgets;
  the separate `/mh-todos` overlay retains its frame and session-journal behavior.

## Continuity and reliability

- Maintained memory handles tree-navigation retirement and reactivation, bounded
  diagnostics and metadata-only compaction provenance. Palace is a read-only
  observer, not another memory owner. Retained drafts, cross-project hard-link
  residue and older-parser compatibility have explicit limits; see
  [maintained memory](../agent-memory.md).
- First-use memory reply validation and Code Map installation grants were
  corrected. Ordinary memory reads are completion-driven and caller-cancellable
  instead of sharing the 30-second mutation/publication deadline.
- Automatic RTK Bash interception is retired. Native execution stays under PSS
  receipts, revocation and final current checks; RTK remains an explicit,
  non-executing rewrite preview and new installations default it to off. The guard
  host no longer retains either legacy guard factory at runtime: commit arguments
  are not custom-rewritten, while secret protection uses bounded operand rules and
  filtered inspectors; see [Guards](../guards.md) and [RTK](../rtk.md).
- An optional advisory for the exact GPT-6.1 Terra primary route encourages
  continuation within existing authorization boundaries. The limited live pilot
  did not demonstrate an advantage; it is not a scheduler or an automatic action.

## Verification and boundaries

Source and public SDK/Faux checks do not establish installed activation, provider
behavior, complete memory parity or recovery of private storage. Mahiro accepted
the visual direction for this release; another terminal or theme can render colors
differently. Profile installation and reload remain separate from publication.

This package remains `private: true` / `UNLICENSED`. This is a GitHub source
release, not npm publication or a license grant.
