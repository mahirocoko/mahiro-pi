# v0.12.1 source release record — 2026-11-03

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release aligns the default maintained-memory starter persona
with the Letta Code Memo persona while preserving generic companion naming and
single-file preview bounds.

## Default starter persona and Tiered v2 migration

- `lib/agent-memory/starter.ts` defines `starterPersonaBody` and `starterPersona`
  adapted from Letta Code's `src/agent/prompts/persona_memo.mdx` under
  Apache-2.0, keeping generic `Companion` naming on the opening line and
  bounding `starterCore` within the 4,000-character single-file read preview.
- `migrate-v2` in `lib/agent-memory/engine/data.ts` seeds `system/persona.md`
  with `starterPersona` when migrating an uncustomized `starterCore` store,
  while preserving customized `Core.md` content.
- `THIRD_PARTY_NOTICES.md` records Apache-2.0 attribution for
  `src/agent/prompts/persona_memo.mdx`.

## Verification and boundaries

The source is checked with Biome formatting, strict authored TypeScript,
package and documentation validation, whole-state budget accounting and focused
starter and profile-installation suites. Source and deterministic SDK checks do
not establish provider behavior, live profile state or human visual acceptance
in every environment. Installing or upgrading this source release still requires
an intentional profile preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
