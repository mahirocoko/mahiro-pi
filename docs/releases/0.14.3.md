# v0.14.3 source release record — 2026-11-17

[← Documentation](../README.md) · [Current installation](../getting-started.md) · [Guards and permissions](../guards.md)

This patch updates the pinned public permission-system from **42.0.0 to 42.0.2**.
The upstream fix evaluates a subagent's forwarded Bash command in its supported
spellings on the parent, preserving parent-side command restrictions when the
child's working directory differs. Pi **1.5.2** and subagents **25.0.5** stay
unchanged.

## Preserve the authored guard patch

The existing 319-line PSS patch is renamed for 42.0.2 without changing its bytes.
It retains winning-surface metadata, principal-bound aggregate Bash approval
consumption, one-shot receipts and revocation. This update does not disable Root,
relax public PSS policy, add permissions or change memory authority.

Bootstrap/setup pins, the frozen lockfile and current dependency guides now agree
on 42.0.2. Stable package registrations and the matching native-child exclusion
remain the supported installed locators; transient package-store paths are not
profile registrations.

## Forwarding regression and verification scope

The focused regression uses the real upstream Bash parser, gate, forwarding-wire
reader and parent resolver. It checks child-directory command spellings against a
parent deny and ensures malformed forwarded spellings do not imply an allow.
Existing approval and native-child checks retain their patched/unpatched controls.

The source release gate is `pnpm check:release`: fast static checks, the serial
source suite, the genuine public-SDK/Faux suite and final whole-state accounting.
Disposable SDK profiles are not the installed profile, and synthetic checks alone
do not establish installed readiness or semantic memory quality.

A separately authorized fresh installed Pi session exercised startup, native Read
and Bash, one native child read and ABI2 memory status. The existing automatic
writer completed and integrated; final status was Ready, idle and no pending
operations. The previously running session was preserved without reload. These
observations cover the exercised runtime path, not exhaustive security,
interleaving or human product acceptance.

## Publication boundary

This is a GitHub source release with an inspected tagged archive and SHA-256
manifest, not npm publication or a license grant. The package remains
`private: true` / `UNLICENSED`. Profiles, private knowledge, transcripts, runtime
evidence and retrospectives stay outside the release payload. Publishing does not
install dependencies, repair unrelated authority behavior, reload sessions,
change models/policy or close human-owned product tasks.
