This patch source release prepares the reflector to follow the primary agent's
current model at each dispatch. It records the source change committed at
`b8fbc89cb14d353194711d82262cda942178830e`; release metadata itself is
not an installed profile change.

## Reflector route and migration

- The source `agents/memory-reflector.md` descriptor now omits `model` and retains
  `thinking: medium`. The continuity controller checks the loaded role metadata,
  preflights the current physical primary model through the public registry and
  pins model/thinking in native spawn options. Inherited non-reasoning models use
  `off` thinking. Missing, virtual or unavailable routes fail closed; there is
  no fallback to another provider or a general agent.
- An explicitly reviewed roles installation can migrate **only** the exact prior
  canonical reflector descriptor with `model: openai/gpt-6.1-sol` and
  `thinking: medium` to the new inherited descriptor. Edited or other fixed
  reflector descriptors still block. The managed-memory writer's independently
  selected route and the git-commit role are unchanged by this reflector change.
- Source updates alone do not rewrite installed descriptors. An existing prior
  canonical reflector needs `pnpm install:profile --preview`, review, then
  `pnpm install:profile` and a fresh session load before the new route can
  dispatch. Installation does not change the primary model or copy credentials.

## Verification and boundaries

`pnpm check:docs` and `pnpm check:fast`. The combined `pnpm check:release`,
full source and public-SDK tiers were not run as part of metadata preparation;
those require separate release-gate authorization. Static checks do not
establish provider behavior, installed activation or human acceptance.
