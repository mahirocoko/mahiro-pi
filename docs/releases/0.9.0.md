# v0.9.0 source release record — 2026-10-27

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This feature release makes `/mh-todos` the primary command for branch-local
session tracking and corrects the native overlay toward Mahiro's supplied
`rpi-todo` visual reference. The existing `/mh-tasks` command remains a
compatibility alias over the same handler and journal.

## Reference-aligned todo card

- The overlay now uses an inset `● Todos (done/total)` heading inside a quiet,
  consistently padded rectangular frame.
- Stable groups show completed todos first, followed by in-progress and pending
  work. Completed rows are muted and struck through; active and pending lifecycle
  markers remain distinct even when a todo has unresolved dependencies.
- A breathing-space row separates completed and unfinished work. The selected
  unfinished row stays visible within the bounded seven-row window, with overflow
  counts for longer lists.
- The footer keeps ownership and keyboard behavior explicit without dominating the
  list. It identifies the surface as branch-local, separate from `tsk` and not
  human acceptance; settings and clear-completed shortcuts name their destinations
  and adapt to narrow widths.
- Empty-state guidance reflects the actions that are actually available. Thai,
  CJK, emoji and narrow layouts continue to use public Pi TUI geometry helpers.

## Command compatibility

- `/mh-todos` is registered as the primary public command and appears as **Todos**
  in the `/mh` workflow hub.
- `/mh-tasks` calls the exact same handler. It does not create a second runtime,
  journal or task owner.
- Internal `mh_task_*` tools, `mahiro-session-tasks-v1` records, revisions,
  dependencies, retention/reminders, stale-context checks and RPC/non-TUI selector
  behavior remain unchanged.
- The contextual widget and fallback dialogs use the Todos name while preserving
  the distinction from the canonical cross-session `tsk` board.
