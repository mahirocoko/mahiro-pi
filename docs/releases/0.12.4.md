# v0.12.4 source release record — 2026-11-04

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release improves Palace history readability, cross-project
directory discovery, `init-project` index seeding, background reflection retry
backoff, and maintained-memory tool normalization and closed-enum failure
diagnostics.

## Palace history headers, cross-project discovery and `init-project` seeding

- `lib/agent-memory/engine/data.ts` retains canonical in-scope `--- <path>` /
  `+++ <path>` file headers in `knowledgeHistory` patches so multi-file commits
  remain distinguishable in the Palace History view while continuing to strip
  raw `diff --git`, rename/copy and external diff headers.
- `lib/palace-render/abi2-page.ts` renders an informational notice when the
  committed history has only the initial snapshot commit, and
  `lib/agent-memory/palace-structure.ts` includes migrated `archives/legacy-v1-*`
  paths across project slugs in Palace structure inspection.
- `lib/agent-memory/engine/schema.ts`, `lib/agent-memory/engine/data.ts` and
  `lib/agent-memory/store.ts` allow primary shared sessions to list `projects`,
  `projects/<slug>`, `projects/<slug>/system` and `projects/<slug>/reference`,
  and update `init-project` to seed `projects/<slug>/system/index.md` alongside
  `overview.md` and `conventions.md`.

## Memory tool normalization, actionable reason codes and reflection backoff

- `lib/agent-memory/retrieval.ts` auto-clamps `limit` to each read mode's ceiling,
  ignores empty-string selector fields when another non-empty selector is
  provided, normalizes leading `/` on relative memory paths and supports
  `topic: 'projects/<slug>'` directly.
- `extensions/mahiro-agent-memory.ts`, `lib/agent-memory/experimental-runtime.ts`,
  `lib/agent-memory/runtime.ts`, `lib/agent-memory/engine/schema.ts`,
  `lib/agent-memory/engine/data.ts` and `lib/agent-memory/store.ts` make
  `sources` optional (defaulting to `[]`), make `expectedHash` optional in
  `mode: 'append'`, make `text` optional in `patch`/`append` modes, normalize
  missing trailing newlines in `mode: 'replace'`, auto-seed YAML frontmatter
  (`name`, `description`) and `# <slug>` headings for new tiered v2 files, and
  harden `remember` to cancel open primary drafts and seed frontmatter on
  missing target files.
- `lib/agent-memory/reasons.ts` and `lib/agent-memory/reasons.mjs` add closed-enum
  failure codes (`invalid-arguments`, `out-of-scope`, `read-only`,
  `patch-target-not-found`, `patch-target-ambiguous`, `budget`) and actionable
  recovery guidance on `CAS` and `retention`, while `assertLosslessRetention`
  checks top-level `#`/`##` headings and a 35% shrink threshold.
- `lib/agent-memory/reflection-schedule.ts` and
  `lib/agent-memory/experimental-runtime.ts` apply exponential retry backoff to
  failed automatic reflection attempts without penalizing foreground-cancelled
  turns.

## Verification and boundaries

The source is checked with Biome formatting, strict authored TypeScript,
package and documentation validation, whole-state budget accounting and focused
maintained-memory, retrieval, Palace, reflection and SDK usability suites.
Source and deterministic SDK checks do not establish provider behavior, live
profile state or human visual acceptance in every environment. Installing or
upgrading this source release still requires an intentional profile
preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
