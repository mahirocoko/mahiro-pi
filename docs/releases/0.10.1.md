# v0.10.1 source release record — 2026-10-28

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch release preserves an explicit package-skill choice during profile
upgrades and makes workflow attention status easier to interpret.

## Optional repo commit skill

- Fresh profile installations continue to include the repository-owned
  `skills/git-commit` skill by default.
- `--without-git-commit-skill` explicitly excludes that package skill, while
  `--with-git-commit-skill` restores it. Preview and apply remain separate.
- Ordinary upgrades preserve the exact supported exclusion instead of silently
  restoring the default. The installer still rejects aliases, additional fields,
  other resource filters and filters on required permission/subagent owners.
- Package-skill selection does not remove the separately installed
  `agents/git-commit.md` system role and never authorizes a commit by itself.

## Clearer workflow attention

- The shared above-editor attention row now labels returned owner metadata as an
  observed status rather than an unexplained blocker.
- Each feature points to its own status command, such as `/mh-goal status`, and
  states that the projection is informational rather than a permission gate.
- Existing two-row bounds, terminal-width truncation, owner/session binding,
  lifecycle expiry and privacy-safe fixed wording remain unchanged.

## Verification and boundaries

Formatting, type, documentation, package, focused bootstrap and workflow tests,
and independent source review cover the changed contracts. Source/Faux checks do
not prove installed activation or rendered behavior in every terminal. Profile
apply and session reload remain separate from this publication.

This package remains `private: true` / `UNLICENSED`. This is a GitHub source
release, not npm publication or a license grant.
