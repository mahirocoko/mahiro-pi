## Read learned skills in Memory Palace

Run `/mh-memory palace` from an idle ABI2 Main TUI in the opted-in project and open **Learned Skills**. The tab shows the active skill's description, eligible roles, exact revision and rendered Markdown. Run the command again for a new snapshot after publication, rollback or disable.

The tab uses existing read policy and exact project scope. It does not move skills into memory, show drafts or review reports, or make skills visible to new roles. Eligible skills are copied into the existing private HTML snapshot; older exported copies are not revoked.
