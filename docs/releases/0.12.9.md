# v0.12.9 source release record — 2026-11-06

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release normalizes and deduplicates `sources` in
`agent_memory_edit`, retires unpublished primary-session preparation plans when
an edit or commit aborts before publication, and adds a one-step
`/mh-memory cleanup` command (`agent_memory_manage` `{ "action": "cleanup" }`)
and TUI menu entry to cancel active drafts, reconcile ownerless prepared
journals, and reclaim stale drafts, journals and overlay blobs.

## `agent_memory_edit` source normalization and primary-session skill guidance

- `lib/agent-memory/experimental-runtime.ts`, `lib/agent-memory/runtime.ts`,
  `lib/agent-memory/engine/data.ts` and `lib/agent-memory/store.ts` normalize,
  filter and deduplicate `sources` into sorted valid identifiers during
  `agent_memory_edit` (and auto-synced index edits) so free-text or duplicate
  episode labels passed during interactive sessions do not fail closed with
  `Unsafe memory content` (`reason: unknown`).
- `skills/maintaining-core-memory/SKILL.md`,
  `skills/maintaining-deferred-memory/SKILL.md` and
  `skills/initializing-memory/SKILL.md` instruct primary-session interactive
  edits to omit `sources`, reserving `sources` for observed episode IDs during
  background reflection.

## Unpublished primary preparation retirement

- `lib/agent-memory/experimental-runtime.ts` adds `retirePrimaryUnpublished(view)`
  around primary-session `prepare` → `publish` flows (`agent_memory_edit` with
  `commit: true`, `agent_memory_commit`, `remember`, and `init-project` /
  `migrate-v2`) so an aborted or failed preparation retires its unpublished
  plan rather than leaving an ownerless `prepared` journal on disk.

## `/mh-memory cleanup` and `agent_memory_manage` `cleanup` action

- `lib/agent-memory/engine/protocol.ts`, `lib/agent-memory/engine/replies.ts`,
  `lib/agent-memory/engine/controller.ts`, `lib/agent-memory/engine/data.ts`,
  `lib/agent-memory/store.ts`, `lib/agent-memory/experimental-runtime.ts`,
  `lib/agent-memory/runtime.ts` and `extensions/mahiro-agent-memory.ts` add
  `/mh-memory cleanup`, a **Cleanup drafts** item in `/mh-memory` →
  `Diagnostics & Maintenance`, and `agent_memory_manage` `{ "action": "cleanup" }`.
- `cleanup` cancels any active uncommitted primary draft, retires unpublished
  controller plans in memory, reconciles ownerless `prepared` journals on disk
  when no `.lock` is held and the Git index/worktree are clean at `plan.current`,
  and force-reclaims `.tmp` files, `committed`/`cancelled`/expired/discarded
  drafts, terminal journals and unreferenced overlay blobs.
