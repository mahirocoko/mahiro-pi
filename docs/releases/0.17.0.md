# v0.17.0 source release record — 2026-11-28

[← Documentation](../README.md) · [Project skill-learning pilot](../skill-learning.md)

## Learn a reusable procedure from specialist work

- In one explicitly enabled project, Main can turn a collected native implementer result into one small project procedure. A native verifier independently reviews the proposed Markdown before it becomes active. Rejected proposals leave the active revision unchanged.
- Fresh eligible implementers and verifiers can discover and read the selected revision from Pi's native skill catalogue. Other roles and projects do not inherit it. An operator can disable future discovery or roll back the active revision without deleting the stored files.
- Learning is off by default and grants no permissions. Existing tool and file rules still apply. This release does not change maintained memory or install or enable the pilot in an existing profile.

## Verification and known limits

The focused native SDK test exercised rejection, revision-specific discovery and use, project and role isolation, and rollback. A live Pi run also demonstrated rejection without activation and a fresh verifier finding and using a subsequently published revision without its name or path in the assignment.

The prior full source suite had 1,360 passes, two failures, three skips, and two todos. Both failures were reproduced on the preceding base: the Todos RPC fixture lacks a status method, and the offline restore fixture's expected intermediate file mode depends on the inherited umask. The combined release gate was not rerun for this release.

This is a GitHub source release, not npm publication. Private profile state, runtime evidence, and learned skill contents are not included.
