## Control Orch from T3 Code

In a Pi session with the optional orchestrator extension loaded, run `/mh-orchestrate on`, `/mh-orchestrate off`, or `/mh-orchestrate status` as a standalone command. T3 Code displays the native status notice without requiring a terminal footer. The bare command still toggles the mode. New sessions start OFF. Mode changes do not invoke the model or start a worker.

When orchestration is on, its run guidance also remains visible when an earlier extension such as Managed Memory supplies a flat system prompt. Worker dispatch still uses the existing PSS-guarded Subagents route and configured `implementer` role.
