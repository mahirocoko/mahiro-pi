# v0.12.6 source release record — 2026-11-05

[← Documentation](../README.md) · [Current installation](../getting-started.md)

This patch source release adds automatic ABI2 namespace capacity reclamation for
terminal and expired metadata records, bounded in-memory certificate and
preparation-map eviction, worker draft cancellation on early cleanup, and
workflow attention warnings for `/mh-memory doctor` and `/mh-memory capacity`.

## Automatic ABI2 namespace capacity reclamation and bounded eviction

- `lib/agent-memory/engine/data.ts` adds `reclaimNamespaceCapacity()` during
  `initializeNamespace()` when the operation journal reaches
  `overflowJournalCutoff` (36) or the draft directory reaches `limits.views`
  (64). It reclaims terminal `committed` drafts, expired non-conflict drafts
  (`open`, `ready`, `cancelled`) that are not locally active or referenced by an
  active nonterminal journal, and expired `conflict` drafts that have been
  explicitly marked in `discarded/<id>.json`, along with unreferenced overlay
  blobs in `blobs/`, `reconciled_committed` journal entries for reclaimed,
  expired-overflow, or orphaned views, and ownerless `not_committed_dirty`
  journal entries for reclaimed drafts. Active drafts, unreviewed `conflict`
  proposals, and nonterminal journals remain preserved.
- `lib/agent-memory/engine/data.ts` FIFO-evicts the oldest cached entry when
  `this.certificates.size` exceeds 32,768 instead of failing with a capacity
  error, matching `this.bases`.
- `lib/agent-memory/engine/controller.ts` evicts `retired` or
  `published && drained` entries from `this.preparations` before enforcing the
  64-entry preparation ownership limit.
- `lib/agent-memory/experimental-runtime.ts` cancels unpublished worker drafts
  after `retireUnpublished` during leased-view cleanup.

## Workflow attention warnings for memory doctor and capacity diagnostics

- `lib/workflow-attention.ts` extends `workflowAttention('memory', result)` to
  flag numeric `conflicts > 0`, `healthy === false`, non-empty `blockers`
  (`status`, `doctor`, or `admission`), `views >= 48`, `episodes >= 192`,
  `missingDescriptions`, and `unmigratedV1Paths`.
- `extensions/mahiro-agent-memory.ts` emits `'warning'` notifications for
  `/mh-memory doctor` and `/mh-memory capacity` when `workflowAttention`
  identifies an attention condition, alongside the two-line `aboveEditor`
  workflow attention widget.
- `test/agent-memory-engine.test.ts` and `test/workflow-attention.test.ts` add
  regression coverage for namespace capacity reclamation and diagnostic warning
  projections.

## Verification and boundaries

The source is checked with `pnpm format`, `pnpm check:fast` (`check:state`,
`check:types`, `check:format`, `check-package.mjs` and `check:docs`), and
focused maintained-memory, workflow-attention, lifecycle, reflection, and
offline-maintenance suites. Source and deterministic SDK checks do not establish
provider behavior, live profile state or human visual acceptance in every
environment. Installing or upgrading this source release still requires an
intentional profile preview/apply and fresh session load.

The release archive is built from the annotated tag, inspected for private-state
paths and published with a SHA-256 manifest. This package remains
`private: true` / `UNLICENSED`; this is a GitHub source release, not npm
publication or a license grant.
